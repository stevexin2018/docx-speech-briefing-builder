# v2.0.5 — 日常朗读入口统一

此前通过人工试听的 v2.0.5rc1/rc2 仍在独立开发分支，日常 Windows 与 ARM
入口使用 v2.0.4，导致“下标……下标结束”等旧读法继续出现。本版合入这些修正。

- 简单下标以短暂停顿连接：`L_{\text{span}}` → “L、span”，
  `W_{m2}` → “W、m二”；复杂下标仍保留必要结构提示。
- 分式使用“除以”和必要的括号范围，去掉机械的开场与结束提示。
- 数值和计量单位相连，减少“5，毫米”一类不自然停顿。
- 保留网址分隔符修复；数学除法、分数与复合单位保持原有含义。

语音缓存包含清洗结果与相关代码指纹，旧读法的缓存会在下次构建时失效。
已生成或转发的 MP3 不会自动改变；视频复用原音频，也不会修正其中的读法。
需要更正已有成品时，应重新生成 MP3，再将新音频绑定到视频资料包。

本版沿用此前的人工试听反馈。自动测试与构建成功不替代新报告的人工试听，
也不构成工程结论验收。
