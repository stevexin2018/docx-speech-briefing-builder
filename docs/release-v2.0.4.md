# v2.0.4 — section sketches and engineering narration

This release includes the v2.0.3 fixes for decorative section-sketch lines,
subscript and unit narration, and inch quotation marks inside math. It also
restores the existing `Ra 3.2 to 6.3 micrometers` speech rule, which the ARM
managed-update gate caught before v2.0.3 reached the server.

MP3. Private daily reports and generated media are not part of this release.
Technical tests do not replace visual inspection or manual listening.
